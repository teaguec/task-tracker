Task Tracker CLI

A simple command line task tracker written in Python. Tasks are stored in a local JSON file, so there are no dependencies to install.

Project page: https://roadmap.sh/projects/task-tracker

Requirements
Python 3.10 or newer (the script uses match statements)
Setup
Clone the repository:
   git clone https://github.com/<your-username>/<your-repo>.git
   cd <your-repo>
Run the script with python tasktracker.py <command>.

A file.json file is created automatically in the current directory the first time you run a command.
